# 🚡 דוכן החילוץ

משחק פיקסל-ארט קטן בהשראת "מלך הפלאפל".
הרכבלית בחיפה נתקעה בין לב המפרץ לטכניון. בקרונות: סטודנטים לפני מבחן, סבתא, חייל, תייר וכלב – ואתם מפעילים את הדוכן היחיד שעונה להם.

## איך משחקים
1. מסתכלים מה הקרון מבקש (בועה עם פריטים ופס סבלנות)
2. לוחצים על המגשים בדוכן – המצרכים עפים לסל הגדול (☕ קפה, 🔋 מטען, 💧 מים, במבה, 🧆 פלאפל, 🧣 שמיכה)
3. לוחצים על הקרון – הסל עולה בכבל
- 📞 אינטרקום מצלצל? לוחצים עליו מהר כדי להרגיע את הקרון
- 💨 ברוח הסל מתנדנד ומפיל דברים – עדיף לחכות

3 משמרות, מ-16:00 עד 20:00: אחר הצהריים ← שקיעה ← לילה בחיפה. בין המשמרות קונים שדרוגים עם הטיפים.
מקלדת: 1–6 מצרכים, Q/W/E קרונות, רווח לאינטרקום, Backspace לפח.

## טכנולוגיה
HTML, CSS ו-JavaScript בלבד. עולם ברזולוציה 384×216 שמוגדל בפיקסלים חדים, טקסט עברי שמצויר בפיקסלים, וסאונד צ׳יפטיון שנוצר ב-Web Audio. בלי ספריות ובלי קבצי תמונה.
